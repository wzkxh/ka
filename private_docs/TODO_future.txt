PEP 393 — Flexible String Representation.
Depending on the largest character in a string:
- 1 byte per character — if all characters fit in Latin-1 (U+0000–U+00FF).
- 2 bytes per character — if all characters fit in BMP (U+0000–U+FFFF).
- 4 bytes per character — if any character is above U+FFFF.

int64_t rand_int64(int64_t n)
{
  uint64_t range = (uint64_t)n;
  // Largest multiple of range that fits in uint64_t, shifted to threshold
  uint64_t threshold = -range % range;
  uint64_t r;
  do { r = next_u64(); } while(r < threshold);
  return (int64_t)(r % range);
}
