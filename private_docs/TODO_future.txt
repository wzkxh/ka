initializations
===============
1. Static error: The compiler detects an obvious read-before-write in control flow and rejects it.
2. Static warning: The compiler cannot establish initialization, but cannot establish the opposite either. it issues a warning.
3. Runtime check: An optional compilation setting (and pragma on file or function level) inserts
initialization tracking and checks every read.

string optimization (SSO), and your proposed tagged 64-bit representation is a particularly compact implementation.

A few observations:
- 7 bytes of inline data + 6 bits of length + 1 tag bit = exactly 64 bits.
- Longer strings use a pointer to allocated storage.
- Assignment of short strings copies the word.
- Concatenation creates a new value, as you intend.
- Empty string is simply length zero; no allocation.

static uint64_t state = 0x123456789ABCDEF0ULL; // Must be seeded
uint64_t next_u64(void)
{
  uint64_t z = (state += 0x9E3779B97F4A7C15ULL);
  z = (z ^ (z >> 30)) * 0xBF58476D1CE4E5B9ULL;
  z = (z ^ (z >> 27)) * 0x94D049BB133111EBULL;
  return z ^ (z >> 31);
}
// yield 64-bit int 0..n-1, n>1
int64_t rand_int64(int64_t n)
{
  return (int64_t)( next_u64() % (uint64_t)n );
}
// float64 in [0.0, x), x>0
double rand_float64(double x)
{
  // 0x1.0p-53 is 2^-53 (1.1102230246251565e-16)
  double unit = (next_u64() >> 11) * 0x1.0p-53; // Strictly in [0.0, 1.0)
  double result = unit * x;
  // Guard against edge-case floating-point rounding when unit is 1.0 - 2^-53
  if (result >= x) { result = __builtin_nextafter(x, 0.0); }
  return result;
}

def is_prime(n): # int64 -> int64 (0|1)
  if n < 66:
    if n < 2: return 0
    return (0x28208A20A08A28AD >> (n - 2)) & 1
  if (n & 1) == 0 or (n % 3) == 0: return 0
  i = 5
  while i * i <= n:
    if (n % i) == 0 or (n % (i + 2)) == 0: return 0
    i += 6
  return 1
